## SALES ANALYSIS PROJECT (MYSQL) 
<br>
<br>
# OVERVIEW
<br>
This project focuses on analyzing sales data using MYSQL.
The goal is to extract meaning insights related to sales performance, customers, products, and orders cetegories.
<br>
<br>
# TOOLS USED 
<br>
-MYSQL
-MYSQL WORKBENCH
-GIT/GITHUB
<br>
<br>
# DATABASE USED 
 DataBase Name: SALES
<br>
<br>
# ANALYSIS QUERiES 
-Top 3 Customers.
-Grand total & Total order.
-Products revenue by categories. 
-Most sold Products.
-Daily sales.
-Average delivery days.
